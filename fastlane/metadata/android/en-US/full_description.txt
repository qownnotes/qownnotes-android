QOwnNotes is an offline-capable Markdown notes app for Android that synchronizes with your own
Nextcloud server.

The Nextcloud Files Android app and a server with Nextcloud Notes API 1.2 or newer, provided by
Nextcloud Notes or QOwnNotes for Nextcloud, are required for Nextcloud accounts. Nextcloud Files manages
your login credentials. Its Single Sign-On library stores an account access token in QOwnNotes'
private preferences, not in the notes database.

Without Nextcloud, you can also use a folder on the device, laid out like a QOwnNotes desktop note
folder, for example one synchronized with Syncthing. No storage permission is needed.

Features include:

* Read, search, create, rename, edit, and delete notes while offline
* Conflict-safe synchronization using ETags and durable pending changes
* Local note folders without Nextcloud, with conflict detection and a restorable trash
* CommonMark and GitHub Flavored Markdown rendering and source editing
* QOwnNotes wiki links, task states, note naming, subfolders, and favorites
* Move or copy notes between subfolders and duplicate notes
* Share notes through public Nextcloud links with password protection and optional editing
* Reorder checklist blocks by dragging; long-press a checkbox to copy its block or delete it
* Note tags shared with QOwnNotes desktop, with tag filtering in the note list
* Create, browse, search, edit, and archive Nextcloud Deck cards and insert card links
* Safe remote images and authenticated Nextcloud note attachments
* View images full screen with zoom, copy them, or annotate a new copy without overwriting originals
* Home-screen widgets for note lists and selected notes
* Browse, edit, and delete bookmarks offline, and insert images while editing notes
* Take photos while editing notes, with configurable photo resolution
* Record audio notes from the app or widget and play audio attachments in the app
* Light and dark themes on Android 9 and newer
* Browse and restore note versions and remote trash through QOwnNotes for Nextcloud or QOwnNotesAPI
* Search across note versions with match counts, highlighted excerpts, and preview match navigation

QOwnNotes contains no advertising, analytics, or developer-operated telemetry. Notes are stored on
the device and synchronized only with the Nextcloud server or local folder selected by the user.

Images load automatically when a note is opened. Remote HTTPS images contact the hosts referenced
in the note, which can see your IP address and request metadata. The note menu's "Load images"
toggle can disable image loading for the current view; it resets to enabled when the note is
reopened. Nextcloud note attachments are loaded from your selected server through Single Sign-On.
